QuickJS for elf2x68kで一部のIOCS関数を使えるようにしました。

追加した関数の仕様は以下となります。

iocs.crtmod( mode ) : CRTモードの設定
	mode: IOCS CRTMODの引数と同じ。引数を-1にすると現在のモードを返します。
	返り値： モードを指定した場合は-1が返ります。modeに-1を指定した場合は現在の設定値を返します。

iocs.g_clr_on() ： グラフィック画面のクリアと表示モードの設定
	返り値： 常にゼロを返します

iocs.gpalet( palet, color ) ： グラフィックパレットの設定
	palet : パレットコード
	color : カラーコード。-1を指定すると戻り値が現在の設定値になります。
	返り値： _iocs_gpaletの返り値をそのまま返します。カラーコードに-1を設定した場合は現在の設定を返します

ioca.apage( page ) : グラフィック描画ページの設定
	page : 書き込みページ番号。-1を指定すると返り値が現在の設定ページを返します。
	返り値： _iocs_apageの返り値をそのまま返します。

iocs.vpage( page ) ：グラフィック表示ページの設定
	page : 表示ページ設定。 bit0-3がページ0-3に対応している
	返り値： _iocs_vpageの返り値をそのまま返します。

iocs.home( page, x, y ) ： グラフィック画面の表示位置設定
	page ： 表示位置を設定するページ。bit0-3がページ0-3に設定している。0ですべてのページに設定
	返り値： _iocs_vpageの返り値をそのまま返します

iocs.windows( x1, y1, x2, y2 )
	x1, y1, x2, y2 : 描画領域のクリッピング範囲の設定
	返り値： _iocs_windowsの返り値をそのまま返します

iocs.wipe() ：グラフィック画面のクリア
	返り値：_iocs_wipeの返り値をそのまま返します

iocs.pset( x, y, c ) ：グラフィック画面に点を打つ
	x, y, c : 座標x, yの位置にパレットコードcの色で点を表示します
	返り値： _iocs_psetの返り値をそのまま返します

iocs.point( x, y ) : グラフィック画面上の指定した点のパレットコードを取得する
	x, y : 調べるグラフィック画面の座標
	返り値： パレットコードを取得できた場合はその値を返します。取得不可の場合は-1を返します

iocs.line( x1, y1, x2, y2, c, style ) ：グラフィック画面に線を引きます
	x1, y1 : 線の始点座標
	x2, y2 : 線の終点座標
	c : パレットコード
	pattern : ラインスタイル
	返り値： _iocs_lineの返り値をそのまま返します

iocs.box( x1, y1, x2, y2, c, style ) : グラフィック画面に箱を描きます
	x1, y1 : 線の始点座標
	x2, y2 : 線の終点座標
	c : パレットコード
	style : ラインスタイル
	返り値： _iocs_boxの返り値をそのまま返します

iocs.fill( x1, y1, x2, y2, c ) ：グラフィック画面に中を塗りつぶした箱を描きます
	x1, y1 : 線の始点座標
	x2, y2 : 線の終点座標
	c : パレットコード
	返り値： _iocs_fillの返り値をそのまま返します

iocs.circle( x, y, r, c, start, end, ratio ) ：グラフィック画面に円(円弧／扇形)を書きます
	x, y : 中心座標
	r: 半径
	c: パレットコード
	start, end : 開始角、終了角(負の数字を指定すると扇形)
	ratio: 比率(256でピクセル比1:1の場合の正円になるように描画)
	返り値： _iocs_circleの返り値をそのまま返します

iocs.paint( x, y, c ) :グラフィック画面の塗りつぶし
	x, y : 塗りつぶし開始座標
	c: パレットコード
	返り値： _iocs_paintの返り値をそのまま返します

iocs.symbol( x, y, str, mx, my, c, type, angle )
	x, y, : 描画開始座標
	str : 描画文字列
	mx, my : 縦横それぞれの表示倍率
	type : フォントタイプ(0:12dot, 1:16dot, 2:24dotの各フォント)
	angle : 文字の向き
	返り値： _ioca_symbolの返り値をそのまま返します
	※QuickJSはShiftJIS文字列の取扱いを保証してないため、ASCII文字列のみの対応となります。
