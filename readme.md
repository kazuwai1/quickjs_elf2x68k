# quickjs for x68k(elf2x68k)
quickjs 2026-06-04 を elf2x68kを使ってx68k向けにビルドしてみました。  

## ビルド
* 環境をローカルへコピーして make でビルド出来ます。以下のファイルが生成されます。
    * qjsc.x : quickjsインタプリタ本体
    * qjsc : *.jsファイルを実行形式(*.x)やバイトコードに変換します
    * libquickjs.a : qjscを使用する際にカレントディレクトリに置いておく必要があります
qjscをビルドするためにはelf2x68kを動かしているホスト環境のCコンパイラやアーカイバを使用します。  

## インストール
### インタプリタを使用する
　ビルドした qjs.x をx68kの環境変数PATHの通ったディレクトリにコピーします。  
　"qjs hoge.js"でjsファイルを実行できます。  
　起動オプションは "qjs --help" で確認できます。  

### qjscで実行ファイル(*.x)を作ってみる
　elf2x68kをインストールしたホスト環境の適当なディレクトリに qjsc, libquickjs.a, コンパイルしたいjsファイルを置きます。  
　"qjsc -o 実行ファイル名(*.x) 入力ファイル名(*.js)"でコンパイルします。  
　生成された実行形式ファイルを x68k 環境へコピーして実行します。
